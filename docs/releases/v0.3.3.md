## Netzwart 0.3.3 – Security hardening

*Deutsch weiter unten.*

A review of the whole project found nothing critical. This release closes the remaining medium and low findings.
No new features, no database change.

### Fixed

- **Initial setup behind a reverse proxy:** while no account existed, setup through a proxy on the same host
  (e.g. Nginx Proxy Manager, Traefik, a tunnel) was possible from anywhere. Forwarded requests now only count from
  proxies listed in `NETZWART_TRUSTED_PROXIES`; otherwise set Netzwart up once directly via its IP address.
- **Login throttling** can no longer be flooded with many addresses or user names (IPv6 counts per /64, hard limit).
- **Notifications** no longer follow redirects, so keys in headers stay with their destination.
- **FRITZ!Box session ID** no longer appears in log messages.
- **Ping** only accepts replies from the device that was pinged.
- **Live updates** end after the maximum session lifetime (30 days).
- **`factory-reset` from the command line** now takes effect at the next start, so the running server cannot write
  old settings back.
- **E-mail:** lines starting with a dot no longer arrive with two dots.
- Cloud metadata services outside link-local are blocked for outgoing connections.
- A warning in the log when Netzwart runs behind a reverse proxy that is not trusted.

### Updating

- **Docker Compose:** `docker compose pull && docker compose up -d`
- **ZimaOS / CasaOS:** set the image tag in the app settings to `0.3.3` and save.
- **Unraid:** *Check for updates*. **TrueNAS:** edit the app and save.

## Netzwart 0.3.3 – Sicherheitshärtung

Eine Prüfung des ganzen Projekts hat nichts Kritisches gefunden. Diese Version schließt die übrigen mittleren und
kleinen Befunde. Keine neuen Funktionen, keine Änderung an der Datenbank.

### Behoben

- **Ersteinrichtung hinter einem Reverse-Proxy:** Solange noch kein Konto existierte, war die Einrichtung über einen
  Proxy auf demselben Rechner (z. B. Nginx Proxy Manager, Traefik, ein Tunnel) von überall möglich. Weitergeleitete
  Anfragen zählen jetzt nur von Proxys aus `NETZWART_TRUSTED_PROXIES`; sonst einmal direkt über die IP einrichten.
- **Login-Bremse** lässt sich nicht mehr mit vielen Adressen oder Namen fluten (IPv6 je /64, feste Grenze).
- **Benachrichtigungen** folgen keinen Weiterleitungen mehr; Schlüssel in Headern bleiben bei ihrem Ziel.
- **FRITZ!Box-Sitzungs-ID** erscheint nicht mehr in Log-Meldungen.
- **Ping** akzeptiert nur Antworten des angepingten Geräts.
- **Live-Aktualisierung** endet nach der maximalen Sitzungsdauer (30 Tage).
- **`factory-reset` über die Kommandozeile** wirkt beim nächsten Start; der laufende Server kann keine alten
  Einstellungen zurückschreiben.
- **E-Mail:** Zeilen, die mit einem Punkt beginnen, kommen nicht mehr mit zwei Punkten an.
- Metadaten-Dienste von Cloud-Servern außerhalb von Link-Local sind für ausgehende Verbindungen gesperrt.
- Warnung im Log, wenn Netzwart hinter einem nicht vertrauten Reverse-Proxy läuft.

### Aktualisieren

- **Docker Compose:** `docker compose pull && docker compose up -d`
- **ZimaOS / CasaOS:** In den Einstellungen der App beim Image `0.3.3` eintragen und speichern.
- **Unraid:** „Nach Updates suchen“. **TrueNAS:** App bearbeiten und speichern.

Das Image ist für `linux/amd64` und `linux/arm64` gebaut und mit cosign signiert.
