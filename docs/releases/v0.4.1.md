## Netward 0.4.1 – Centred ring

*Deutsch weiter unten.*

- The router now sits exactly in the centre of the network ring, where all lines meet. Before, the router together
  with its name and address was centred, which pushed the icon above the middle.
- Screenshots and preview images updated.

### Updating

- **Docker Compose:** `docker compose pull && docker compose up -d`
- **ZimaOS / CasaOS:** set the image tag in the app settings to `0.4.1` and save.
- **Unraid:** *Check for updates*. **TrueNAS:** edit the app and save.

## Netward 0.4.1 – Zentrierter Ring

- Der Router sitzt jetzt genau in der Mitte des Netzrings, wo alle Linien zusammenlaufen. Vorher war der Router
  zusammen mit Name und Adresse zentriert, dadurch lag das Symbol über der Mitte.
- Screenshots und Vorschaubilder aktualisiert.

### Aktualisieren

- **Docker Compose:** `docker compose pull && docker compose up -d`
- **ZimaOS / CasaOS:** In den Einstellungen der App beim Image `0.4.1` eintragen und speichern.
- **Unraid:** „Nach Updates suchen“. **TrueNAS:** App bearbeiten und speichern.

Das Image ist für `linux/amd64` und `linux/arm64` gebaut und mit cosign signiert.
