## Netward 0.4.0 – New name

*Deutsch weiter unten.*

Netzwart is now **Netward**: a name that works in English and German alike. The project lives at
[github.com/Pyzyi/Netward](https://github.com/Pyzyi/Netward), the image at `ghcr.io/pyzyi/netward`.
No new features. Existing installations keep their data and settings.

### What changes for you

- **Image:** `ghcr.io/pyzyi/netward:0.4.0` (or `latest`). Point your installation at the new image once.
- **Settings and data stay:** the database `netzwart.db` is taken over automatically as `netward.db` at the first
  start. Nothing needs to be exported.
- **Environment variables** are now called `NETWARD_*`. The old `NETZWART_*` names keep working, so an existing
  Compose file runs unchanged. If both are set, the new name wins.
- **Sign in once more:** the session cookie got the new name.
- **Home Assistant:** entities are now called `netward_…`. Netward removes the old `netzwart_…` entities from the
  broker by itself. Automations that refer to the old entity IDs need the new ones. The MQTT base topic stays as
  saved in your settings; new installations use `netward`.
- The command in the container is `/netward` (e.g. `docker exec netward /netward reset-password`).

### Updating

- **Docker Compose:** change the image to `ghcr.io/pyzyi/netward:latest`, then
  `docker compose pull && docker compose up -d`.
- **ZimaOS / CasaOS:** in the app settings set the image to `ghcr.io/pyzyi/netward` with tag `0.4.0` and save.
- **Unraid:** edit the container and set the repository to `ghcr.io/pyzyi/netward:latest`.
- **TrueNAS:** edit the app, set the image to `ghcr.io/pyzyi/netward`, tag `0.4.0`, and save.

## Netward 0.4.0 – Neuer Name

Aus Netzwart wird **Netward**: ein Name, der auf Englisch und Deutsch gleich gut funktioniert. Das Projekt liegt
unter [github.com/Pyzyi/Netward](https://github.com/Pyzyi/Netward), das Image unter `ghcr.io/pyzyi/netward`.
Keine neuen Funktionen. Bestehende Installationen behalten Daten und Einstellungen.

### Was sich für dich ändert

- **Image:** `ghcr.io/pyzyi/netward:0.4.0` (oder `latest`). Die Installation einmal auf das neue Image umstellen.
- **Einstellungen und Daten bleiben:** Die Datenbank `netzwart.db` wird beim ersten Start automatisch als
  `netward.db` übernommen. Nichts muss exportiert werden.
- **Umgebungsvariablen** heißen jetzt `NETWARD_*`. Die alten Namen `NETZWART_*` gelten weiter, eine bestehende
  Compose-Datei läuft also unverändert. Sind beide gesetzt, gilt der neue Name.
- **Einmal neu anmelden:** Das Sitzungs-Cookie hat den neuen Namen bekommen.
- **Home Assistant:** Die Entitäten heißen jetzt `netward_…`. Die alten `netzwart_…`-Entitäten entfernt Netward
  selbst vom Broker. Automationen mit den alten Entitäts-IDs brauchen die neuen. Das MQTT-Basis-Topic bleibt, wie
  es in den Einstellungen gespeichert ist; neue Installationen nutzen `netward`.
- Der Befehl im Container heißt `/netward` (z. B. `docker exec netward /netward reset-password`).

### Aktualisieren

- **Docker Compose:** Image auf `ghcr.io/pyzyi/netward:latest` ändern, dann
  `docker compose pull && docker compose up -d`.
- **ZimaOS / CasaOS:** In den Einstellungen der App als Image `ghcr.io/pyzyi/netward` mit Tag `0.4.0` eintragen und
  speichern.
- **Unraid:** Container bearbeiten und als Repository `ghcr.io/pyzyi/netward:latest` eintragen.
- **TrueNAS:** App bearbeiten, Image `ghcr.io/pyzyi/netward` mit Tag `0.4.0` eintragen und speichern.

Das Image ist für `linux/amd64` und `linux/arm64` gebaut und mit cosign signiert.
