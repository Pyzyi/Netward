# Netzwart

[Netzwart](https://github.com/Pyzyi/Netward) - a self-hosted home network monitor with security checks.

Netzwart finds every device on your network, gives it a readable name, shows who is online, alerts you about new
devices and internet outages, and checks the network for common weak spots. It needs the host network for layer-2
discovery and drops all capabilities after start-up.
